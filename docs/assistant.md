# توثيق المساعد الذكي لنظام محاسبي (Mohasebi AI Assistant)

## 1. نبذة عامة
"مساعد محاسبي الذكي" هو مرشد تعليمي وإرشادي يعمل داخل لوحة التحكم كزر عائم (FAB). يهدف إلى مساعدة المحاسبين والمديرين والمراجعين في فهم واستخدام كافة شاشات ووظائف النظام ودورات العمل المحاسبية خطوة بخطوة.

> [!IMPORTANT]
> **حدود المساعد الأمنية:**
> - المساعد **مرشد إرشادي فقط (Guide Only)**: ليس لديه اتصال بقاعدة البيانات ولا يقرأ أي أرقام أو بيانات مالية حقيقية للشركة.
> - المساعد **لا ينفذ أي عمليات (No Mutations)**: لا يقوم بإنشاء أو ترحيل أي قيود نيابة عن المستخدم، بل يرشده للخطوات الصحيحة داخل الواجهة.
> - المساعد متاح لجميع الأدوار (`admin`، `accountant`، `auditor`) دون اشتراط صلاحية الكتابة، مع إدراكه لدور المستخدم في تنبيهه لحدود صلاحياته.

---

## 2. الإعدادات والمتغيرات البيئية (Environment Variables)

تضاف المتغيرات التالية في ملف `.env`:

| المتغير | القيمة الافتراضية | الوصف |
|---------|-------------------|-------|
| `GROQ_API_KEY` | — | مفتاح خدمة Groq API |
| `GEMINI_API_KEY` | — | مفتاح خدمة Google Gemini API |
| `ASSISTANT_PROVIDER` | `groq` | المزود النشط: `groq` أو `gemini` أو `mock` |
| `ASSISTANT_MODEL` | `qwen/qwen3.8-27b` | الموديل المستخدم (مثل `qwen/qwen3.8-27b` على Groq أو `gemini-3.8-flash` على Gemini) |
| `ASSISTANT_DAILY_TOTAL_LIMIT` | `500` | الحد الأقصى اليومي الإجمالي لطلبات المساعد على مستوى النظام كاملاً |

---

## 3. التبديل بين مزودي الذكاء الاصطناعي (Provider Switching)

تم تصميم نظام المزودات بنمط التجريد (Provider Abstraction) عبر الواجهة `AssistantProvider`:

1. **الاعتماد على Groq (الافتراضي والنشط حالياً):**
   ```env
   ASSISTANT_PROVIDER=groq
   ASSISTANT_MODEL=qwen/qwen3.8-27b
   ```
   - سريع جداً وممتاز في اللغة العربية.
   - يدعم إخفاء وتجاوز الـ reasoning tokens لتسريع الإجابة وتوفير الباندويث.

2. **الاعتماد على Google Gemini:**
   ```env
   ASSISTANT_PROVIDER=gemini
   ASSISTANT_MODEL=gemini-3.8-flash
   ```
   - يستخدم واجهة REST مع SSE Streaming (`streamGenerateContent`).
   - يتطلب تفعيل المفتاح في Google Cloud Console والتأكد من حالته.

3. **المزود الوهمي (Mock Provider) للاختبار والتطوير بدون إنترنت:**
   ```env
   ASSISTANT_PROVIDER=mock
   ```

## 4. التحكم في معدل الاستهلاك والحماية (Rate Limiting & Concurrency)

النظام يطبق القواعد الرقابية التالية في الذاكرة (In-memory):
1. **حد الدقيقة:** 10 رسائل في الدقيقة لكل مستخدم.
2. **حد اليوم:** 100 رسالة في اليوم لكل مستخدم.
3. **الحد الأقصى الإجمالي للنظام:** 500 طلب يومياً (قابل للتعديل عبر `ASSISTANT_DAILY_TOTAL_LIMIT`).
4. **حماية التزامن (Concurrency Lock):** يمنع فتح أكثر من جلسة Streaming متزامنة لنفس المستخدم، مع فك الحظر تلقائياً فور انتهاء أو إلغاء الطلب.

> [!NOTE]
> هذا التصميم مخصص لبيئة PM2 التي تعمل بأسلوب `fork mode` (نسخة واحدة). في حال تم الترقية مستقبلاً إلى `cluster mode` (عدة نسخ)، ينصح بربط الـ Rate Limiter بـ Redis أو قاعدة البيانات PostgreSQL.

## 5. قاعدة المعرفة وتحديثها (Knowledge Base)

توجد مقالات قاعدة المعرفة في المجلد:
`src/lib/assistant/knowledge/`

المقالات الأساسية الـ 12:
- `getting-started.md` — دليل البدء السريع وهيكل القوائم.
- `roles-and-permissions.md` — تفصيل صلاحيات الأدوار الثلاثة.
- `chart-of-accounts.md` — شجرة الحسابات، المستويات، والأرصدة الافتتاحية.
- `journal-entries.md` — قيود اليومية وقواعد القيد المزدوج.
- `ledger.md` — الأستاذ العام، الأستاذ المساعد، وكشوف الحسابات.
- `trial-balance.md` — ميزان المراجعة وتشخيص عدم التوازن.
- `inventory.md` — أذون الإضافة والصرف، كارت الصنف، وطريقة WAC.
- `banks-cash-cheques.md` — الخزائن، البنوك، مذكرات التسوية، ومحفظة الشيكات.
- `cost-centers.md` — مراكز التكلفة وربط القيود والمصروفات.
- `specialized-activities.md` — تكاليف التصنيع، المزارع، التسمين، والاستيراد.
- `financial-statements.md` — قائمة الدخل، الميزانية، والتدفقات النقدية.
- `faq-troubleshooting.md` — المشاكل الشائعة وطرق حلها.

### كيفية إضافة أو تحديث مقال:
1. أنشئ ملفاً جديداً بامتداد `.md` داخل `src/lib/assistant/knowledge/`.
2. يبدأ السطر الأول بالعنوان الرئيسي `# اسم الموضوع`.
3. يقوم `knowledge-loader.ts` آلياً بقراءة الملفات وتخزينها في الذاكرة مع ربطها ديناميكياً بمسار الشاشة التي يقف عليها المستخدم والكلمات المفتاحية في سؤاله.

## 6. ملاحظات خادم Nginx والـ Streaming

- يقوم المسار `/api/assistant/chat` بإرجاع الترويسة:
  `X-Accel-Buffering: no`
- هذه الترويسة توجه Nginx تلقائياً بعدم تجميع أو حجز الحزم (Buffering) وتمرير تدفق الـ SSE مباشرة للمتصفح دون الحاجة لتعديل إعدادات Nginx العامة.
