# مُحاسبي (Mohasby) — نظام محاسبي سحابي متزن للشركات المصرية

> **الموقع الرسمي التجريبي:** [https://mohasby.mahmoudashry.site](https://mohasby.mahmoudashry.site)  
> **اللغة الأساسية:** العربية (`ar_EG` - RTL)  
> **العملة والسياق:** جمهورية مصر العربية (ج.م / ضريبة القيمة المضافة)

---

## 1. نبذة عن النظام (Overview)

**مُحاسبي** هو برنامج سحابي متخصص في إدارة الحسابات المالية، المخازن، التبريد، والتكاليف للشركات التجارية والزراعية والتصنيعية في مصر.
يقدم بديلاً احترافياً متزناً لدفاتر الإكسيل، ويعتمد على معايير القيد المزدوج الصارمة لمنع حفظ أي قيد غير متزن.

### الموديولات المدعومة:
- **قيود اليومية المزدوجة (Double-Entry Journal):** مراجعة فورية لتوازن المدين والدائن مع التحقق التلقائي.
- **المخازن والتبريد (Cold-Storage & Warehouses):** أذونات إضافة وصرف، لوتات، ونسب فاقد مع حدود تنبيه.
- **مراكز التكلفة (Cost Centers):** تتبع تكاليف الأراضي والمواسم والشحنات بالجنيه المصري والدولار.
- **البنوك والشيكات (Banking & Cheques):** تسوية بنكية وجداول استحقاق الشيكات الواردة والصادرة.
- **القوائم والتقارير المالية (Financial Statements):** ميزان المراجعة، قائمة الدخل، والمركز المالي.

## 2. بنية التصميم ونظام الألوان (Design Tokens)

تم بناء التصميم بدون أي قوالب مسبقة مع تجنب الألوان العامة، بالاعتماد على درجات دقيقة تعكس الهوية المحاسبية والوقار المالي:
- **اللون الأساسي:** الأخضر الداكن العميق (`#0c1410` - `green-950`).
- **لون التمييز (Accent Token):** الأخضر المينت الزمردي **`#28A78F`** (`accent-500` / `rgba(40, 167, 143)`).
- **لون الأسطح والخلفيات:** `canvas` (`#F7F5F3`) والكروت البيضاء النقية (`#FFFFFF`).
- **الخطوط الطباعية:**
  - للعناوين: **Noto Kufi Arabic** (أوزان 600 - 800).
  - للنصوص والأرقام: **IBM Plex Sans Arabic** مع تفعيل الأرقام الجدولية `font-variant-numeric: tabular-nums`.

### كيفية تعديل لون التمييز (Swap Accent Token):
يمكنك تغيير اللون المميز بسهولة من خلال ملف `tailwind.config.ts` في قسم:
```typescript
accent: {
  500: '#28A78F', // استبدل اللون هنا
  600: '#208C78', // درجة الـ Hover
}
```

## 4. البنية التقنية (Tech Stack)

- **Framework:** Next.js 14 (App Router)
- **Language:** TypeScript (`strict`)
- **Styling:** Tailwind CSS (Tokens-based)
- **Icons:** `@phosphor-icons/react` + مونوغرام ولوجو SVG مخصص
- **Forms & Validation:** `react-hook-form` + `zod`
- **Internationalization:** `next-intl` مهيأ بالكامل للغة العربية والاتجاه من اليمين لليسار (`dir="rtl"`)
- **Server Process:** Node.js managed via PM2 (Process `mohasby`)

## 6. استبدال محاكي المصادقة (Auth Stub Replacement)

المصادقة الحالية مبنية عبر واجهة خدمة مجردة في `src/lib/auth/stub.ts` ومربوطة بـ `src/middleware.ts`.
لربطها بقاعدة بيانات PostgreSQL حقيقية (مثل Supabase أو Prisma / Drizzle):
1. قم بإنشاء ملف تنفيذ لـ `AuthService` في `src/lib/auth/db-auth.ts`.
2. استبدل الاستدعاء في مسار `src/app/api/auth/login/route.ts` للتحقق من التشفير وإصدار توكن JWT في HTTP-only cookie باسم `mohasby_session`.
3. لا يتطلب ذلك أي تغيير في واجهات المستخدم أو المكونات.

## 8. هيكلية وهندسة لوحة التحكم (Dashboard Shell Architecture)

تعتمد لوحة تحكم **مُحاسبي** على بنية مركزية صارمة، حيث يتم تعريف وتوجيه كافة المسارات الـ 44 والمجموعات الـ 8 من خلال ملف تهيئة موحد ومطبوع بدقة (Typed Navigation Registry).

### 8.1 كيف يقود `nav.config.ts` المنظومة بالكامل
يقع الملف في `src/lib/nav/nav.config.ts`، ويحتوي على الثابت `NAV_GROUPS`. يقود هذا السجل:
1. **القائمة الجانبية الممتدة (Desktop Sidebar - 280px):** المجموعات كـ Accordions تفاعلية مع خطوط إرشادية للمجموعات المتشعبة (`cluster`).
2. **شريط الأيقونات المنكمش (Desktop Rail - 76px):** يعرض أيقونات المجموعات مع تلميحات (Tooltips)، وعند النقر يفتح قائمة عائمة منبثقة (`SidebarFlyout - 264px`).
3. **درج الهواتف والأجهزة اللوحية (Mobile Drawer):** ينزلق من حافة البداية مع غطاء داكن (`scrim`) وحبس التركيز (`Focus Trap`).
4. **شريط التنقل العلوي (Topbar):** يولد مسار التتبع الهرمي (`Breadcrumb`) والعناوين بناءً على المجموعات والعناصر المعرفة.
5. **لوحة الأوامر والبحث السريع (`Ctrl+K`):** تبحث تلقائياً في كافة العناوين والأوصاف مع تطبيع النص العربي.
6. **خريطة النظام بالصفحة الرئيسية (`/dashboard`):** تولد شبكة الروابط السريعة تلقائياً لكل مجموعة بدون أي تكرار يدوي.
7. **المسار الديناميكي المشترك:** ملف `src/app/[locale]/dashboard/[group]/[page]/page.tsx` يتحقق فورياً من صحة `group` و `page` ويولد بيانات الـ Metadata تلقائياً.

---

### 8.2 إضافة صفحة جديدة أو عنقود فرعي (Cluster)
لإضافة صفحة محاسبية جديدة:
1. افتح `src/lib/nav/nav.config.ts`.
2. اختر المجموعة المناسبة في مصفوفة `NAV_GROUPS`، وأضف عنصر جديد:
   ```typescript
   {
     slug: 'new-ledger',
     labelKey: 'newLedger',
     descriptionKey: 'newLedgerDesc',
     cluster: 2, // رقم العنقود للفصل بخط hairline دقيق (اختياري)
   }
   ```
3. افتح `messages/ar.json` و `messages/en.json`:
   - في قسم `nav.items`: أضف التسمية العربية والإنجليزية: `"newLedger": "دفتر اليومية المساعد"`
   - في قسم `nav.descriptions`: أضف الوصف: `"newLedgerDesc": "تسجيل الحركات المساعدة المباشرة."`
4. **الصفحة جاهزة فوراً!** سيعمل المسار `/dashboard/accounting/new-ledger` تلقائياً مع العنوان ومسار التتبع وحفظ آخر الزيارات بدون الحاجة لإنشاء مجلدات أو ملفات إضافية.

### 8.3 تغيير أو ربط أيقونات المجموعات
تتم إدارة وتعيين الأيقونات في مكان واحد فقط: `src/lib/nav/nav.icons.tsx`.
- جميع الأيقونات تعتمد مكتبة `@phosphor-icons/react` بوزن منتظم متناسق (1.5px stroke weight).
- لتغيير أيقونة مجموعة:
  1. استورد الأيقونة من `@phosphor-icons/react` في `src/lib/nav/nav.icons.tsx`.
  2. أضفها إلى خريطة `ICON_MAP`:
     ```typescript
     const ICON_MAP = {
       BookOpen,
       Warehouse: Package, // استبدال الأيقونة هنا
       ...
     };
     ```
  3. سيتم تطبيق التغيير فوراً عبر القائمة الممتدة، شريط الـ Rail، والصفحة الرئيسية.

### 8.4 حفظ حالة القائمة عبر الكوكيز (Zero Layout Shift)
- تحفظ حالة القائمة الجانبية (مفتوحة/منكمشة، والمجموعات المفتوحة) في كوكي `mohasby_nav`.
- يقرأ `src/app/[locale]/dashboard/layout.tsx` الكوكي مباشرة على الخادم (Server-Side) قبل التصيير الأولي للـ HTML، مما يضمن ظهور لوحة التحكم بالعرض الصحيح فوراً **بدون أي وميض أو اهتزاز في التخطيط (Zero Layout Shift)**.

---

### 8.5 تطبيع البحث العربي (Arabic Normalization Engine)
محرك البحث المدمج في `src/lib/nav/search.ts` يعالج أدق تفاصيل الكتابة العربية:
- إزالة التشكيل (الحركات) وعلامات المد (الكشيدة).
- توحيد الهمزات: تحويل `أ`، `إ`، `آ` إلى `ا` المجردة (البحث عن `الاستاذ` يجد `الأستاذ العام`).
- توحيد الياء والألف المقصورة: تحويل `ى` إلى `ي` (البحث عن `المالى` يجد `القوائم المالية`).
- توحيد التاء المربوطة: تحويل `ة` إلى `ه`.
- مطابقة الأرقام: توحيد الأرقام المشرقية (`٠-٩`) والأرقام الغربية (`0-9`).
