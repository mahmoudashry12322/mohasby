# مُحاسبي

تطبيق محاسبة عربي يجمع الواجهة وواجهات API في مشروع Next.js، مع Prisma وPostgreSQL. هذا الفرع يحوّل القوائم التجريبية إلى شاشات مرتبطة بقاعدة البيانات، ويضيف قواعد الحساب المستخلصة من ملف Excel المرجعي.

## ما يعمل

- دليل حسابات شجري، أرصدة افتتاحية، قيود مسودة وترحيل وعكس ومراجعة.
- مستندات شراء وبيع ومرتجعات تربط القيد بالمخزون في عملية واحدة.
- مخازن وثلاجات وأصناف وهالك وجرد، بمتوسط الفترة المرجح وإقفال مخزون.
- أستاذ عام ومساعد وكشوف حساب وميزان مراجعة ودخل ومركز مالي وحقوق ملكية وتدفقات نقدية.
- جداول تكاليف التصنيع والزراعة والإنتاج الحيواني والتصدير والاستيراد: 251 صيغة قابلة للتتبع إلى خلايا المصدر.
- أصول وإهلاك، شركاء وتوزيع أرباح وتسوية تمويل، وحاسبات الوزن والاستيراد.
- دخول بجلسات فعلية، صلاحيات مدير ومحاسب ومراجع، وعزل الشركات وسجل مراجعة.

## التشغيل

ابدأ من [دليل التثبيت والترقية](docs/DEPLOYMENT.md). يتطلب Node.js 22 وPostgreSQL 16. الواجهة والـAPI يعملان من التطبيق نفسه؛ قاعدة البيانات خدمة مستقلة يحددها `DATABASE_URL`.

```bash
npm ci
cp .env.example .env
# اضبط القاعدة وبيانات مديرك في .env
npm run db:generate
npm run db:migrate
npm run db:seed
npm run setup:admin
npm run build
npm start
```

الإنتاج يتطلب HTTPS. لا يوجد حساب تجريبي عام أو كلمة مرور ثابتة. لا تطبق تعليمات التثبيت الجديد على قاعدة قائمة قبل قراءة قسم الترقية.

## المرجع والتحقق

- [خريطة صفحات Excel وقواعد الحساب والتغييرات المتعمدة](docs/WORKBOOK-MAPPING.md)
- [حدود الاختبارات وخطوات قبول نسخة العميل](docs/VALIDATION.md)
- الصيغ التفصيلية: `src/data/cost-templates.json`؛ محرك الحساب: `src/lib/accounting/`.
- Workflow في `.github/workflows/accounting.yml` يختبر PostgreSQL 16 والتزامن والواجهة.

ملف Excel وبياناته الفعلية غير منشورين في المستودع. التطبيق يعمل ببيانات تدخلها أنت؛ ترحيل معاملات العميل القديمة والتحقق من أرصدتها خطوة مستقلة قبل التسليم. العمل الحالي لا يتضمن اشتراكات SaaS أو فواتير إلكترونية ضريبية أو دفتر أستاذ متعدد العملات.

تم تحديث Next.js إلى 16 وReact إلى 19 أثناء التنفيذ لمعالجة الاعتماديات القديمة؛ احتُفظ بهيكل App Router والتصميم الأساسي.
