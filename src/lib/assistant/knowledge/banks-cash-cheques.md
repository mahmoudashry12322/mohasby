# النقدية والبنوك وحدود النسخة

لتسجيل قبض أو صرف استخدم «قيود اليومية» باختيار حساب الخزينة أو البنك وحساب الطرف المقابل، ثم حفظ مسودة وترحيل.
لمراجعة حركة البنك استخدم «كشف حساب» واختر حساب البنك. لتصنيف النقدية استخدم تصنيف التدفق في القيد ودليل الحسابات بحسب إعداد الشركة.
لا توجد ضمن الصفحات الـ43 الحالية شاشة «محفظة الشيكات» ولا دورة تتبع حالات شيك متكاملة. لا تقترح زرًا لمحفظة شيكات أو مذكرة تسوية بنكية آلية. يمكن شرح الفكرة المحاسبية مع توضيح أن الوظيفة غير متاحة كواجهة مستقلة.
