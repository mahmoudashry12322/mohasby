# الأدوار والصلاحيات في نظام محاسبي

## 1. الأدوار المعرفة في النظام
يحتوي نظام محاسبي على ثلاثة أدوار رئيسية (RBAC):

1. **مدير النظام (Admin):**
   - صلاحيات كاملة دون قيود (قراءة، إضافة، تعديل، حذف، ترحيل، وإلغاء).
   - إدارة المستخدمين وتحديد أدوارهم.
   - تهيئة إعدادات الشركة، الفترات المالية، والأرصدة الافتتاحية.
   - الاطلاع على سجل المراجعة وسجل العمليات بالكامل (Audit Log).

2. **المحاسب (Accountant):**
   - إنشاء وإدخال قيود اليومية، أذون المخازن، حركات البنوك، والمستندات.
   - تعديل القيود غير المعتمدة (المسودات).
   - طباعة وتصدير التقارير وكشوف الحسابات.
   - لا يمكنه تعديل إعدادات النظام الحساسة أو إدارة المستخدمين أو تعديل القيود المقفلة في فترات مغلقة.

3. **المراجع / المدقق (Auditor):**
   - صلاحية القراءة والاطلاع فقط (Read-only) على كافة السجلات والتقارير.
   - الاطلاع على دفتر الأستاذ وميزان المراجعة والقوائم المالية وسجل المراجعة.
   - لا يمكنه إنشاء أو تعديل أو حذف أي قيد أو مستند أو رصيد.

## 2. سجل المراجعة (Audit Log)
يسجل النظام كل عملية تتم آلياً:
- هوية المستخدم والوقت الدقيق وتفاصيل الحقول المعدلة (القيمة السابقة والقيمة الجديدة).
- مسار العملية (IP والمستند المرتبط) لضمان الشفافية والامتثال الرقابي.
