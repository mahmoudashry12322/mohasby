# الأدوار والصلاحيات

المدير admin يدير إعدادات الشركة والمستخدمين والصلاحيات والعمليات المسموحة. الموظفون يحصلون على صلاحيات مخصصة يحددها المدير لكل مستخدم (عرض، إضافة، تعديل، ترحيل، إلغاء، عكس، إهلاك، تدقيق).
إدارة المستخدمين والصلاحيات وسجل النشاط متاحة للمدير داخل شاشة الإعدادات وقسم «المستخدمون والصلاحيات»، كما يمكن لمن يملك صلاحية سجل النشاط `audit.view` الاطلاع عليه من أدوات الإدارة.
لا توجد أزرار لإدارة المستخدمين ضمن مجموعة أزرار الإكسل الـ43. الموظف يرى فقط الصفحات والأزرار المسموح له بها. القيود المرحلة تُعكس بقيد عكسي ولا تُحذف بلا أثر.
