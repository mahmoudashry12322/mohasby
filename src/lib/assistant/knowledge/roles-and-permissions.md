# الأدوار والصلاحيات

المدير admin يدير الإعدادات والعمليات المسموحة. المحاسب accountant يسجل العمليات اليومية ضمن الفترات المفتوحة. المراجع auditor للقراءة فقط، والخادم يرفض الحفظ والترحيل منه.
وجود زر على الصفحة لا يعني أن الدور يملك تنفيذه. لا ترشد المراجع لتنفيذ عمليات تعديل؛ وجّهه إلى محاسب أو مدير.
لا توجد في الصفحات الـ43 شاشة إدارة مستخدمين؛ لا تخترع مسارًا أو زرًا لها. القيود المرحلة تُعكس بقيد عكسي ولا تُحذف بلا أثر.
