# حل المشكلات

قيد ناقص: راجع التاريخ والبيان والسطر المشار إليه، ثم اختر الحساب والمبلغ. كل سطر مدين أو دائن، ولا بد من توازن الإجماليين. لا يلزم الخروج أو فقد الإدخال.
خطأ اتصال أثناء الحفظ: راجع قائمة السجلات قبل إعادة الإرسال لأن الرد قد ينقطع بعد تنفيذ العملية. عند انتهاء الجلسة سجّل الدخول في تبويب آخر واحتفظ بتبويب البيانات.
تعذر عرض صفحة: اضغط إعادة المحاولة داخل لوحة التحكم. لا تعتبر كل خطأ واجهة خطأ HTTP 500 ولا تدّع معرفة سبب الخادم دون سجل خطأ.
أرقام التقرير لا تظهر: راجع الفترة ومرشحات الحساب والطرف والمخزن، وأن القيد مرحل، وأن الصنف والمركز مرتبطان بالحركة الصحيحة.
