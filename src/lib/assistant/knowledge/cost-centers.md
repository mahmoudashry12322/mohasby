# مراكز التكلفة (Cost Centers)

## 1. الغرض من مراكز التكلفة
تساعد مراكز التكلفة الإدارة في تحليل وتوزيع المصروفات والإيرادات على الأقسام، المشاريع، المزارع، خطوط الإنتاج، أو الفروع المستقلة، لمعرفة ربحية كل وحدة تشغيلية بدقة دون تضخيم دليل الحسابات العام.

## 2. هيكل مراكز التكلفة
- يمكن إنشاء شجرة مراكز تكلفة بمستويات رئيسية وفرعية:
  - مركز رئيسي: قطاع الزراعة
    - مركز فرعي: مزرعة وادي النطرون (بيفوت 1)
    - مركز فرعي: مزرعة وادي النطرون (بيفوت 2)
  - مركز رئيسي: قطاع التصنيع
    - مركز فرعي: خط تعبئة التمور

## 3. ربط العمليات والقيود بمراكز التكلفة
- عند إنشاء أي قيد يومية، إذن صرف مخزني، أو فاتورة مشتريات/مصروفات، يمكن تحديد مركز التكلفة المرتبط بالسطر.
- الحسابات التي يتم ربطها غالباً بمراكز التكلفة هي حسابات المصروفات (المجموعة 5) وحسابات الإيرادات (المجموعة 4).

## 4. تقارير مراكز التكلفة
- **تقرير ميزان مركز التكلفة:** يعرض كافة الإيرادات والمصروفات المحملة على المركز وصافي ربحه أو خسارته التشغيلية خلال فترة محددة.
- **تقرير مقارنة مراكز التكلفة:** لمقارنة أداء وفعالية التكاليف بين الفروع أو المشاريع المختلفة.
