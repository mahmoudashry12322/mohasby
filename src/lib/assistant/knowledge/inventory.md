# المخزون

قبل «اذن اضافة» أو «اذن صرف» جهز «دليل الاصناف» (الوحدة وحسابات الترحيل) و«دليل المخازن» (مخزن أو ثلاجة).
اكتب التاريخ ورقم الإذن، واختر الصنف والمخزن والكمية والبيان. للوارد أدخل تكلفة الوحدة والحساب المقابل. يمكن إدخال بوليصة الشحن والسيارة والمزرعة والبيفت واللون والملاحظات.
خيار «إدخال الوزن والفارغ بدل الكمية (كجم)» يحسب القائم = الوزن − الفارغ للأصناف بوحدة كيلوجرام.
«حفظ وترحيل» يسجل الحركة. تقييم المخزون بمتوسط الفترة؛ صرف المخزون لا ينشئ تكلفة المبيعات قبل إقفال المخزون. مستند البيع أو الشراء يسجل حركته تلقائيًا؛ لا تكرر إذنًا لنفس المستند.
«كارتة صنف»، «تقرير مخزن»، «ارصدة مخزون» وتقارير الثلاجات صفحات عرض. اختر الفترة والصنف والمخزن؛ لا تدخل الأرصدة يدويًا في التقارير.
